# Usage

The pages under this section are the full CLI reference, generated directly
from bomify's own `--help` output (`bomify --docs-dir <dir>`) — every
command, every flag, always in sync with the binary. They're not
hand-written, so if something here looks wrong, the fix belongs in the
command's `Short`/`Long`/flag descriptions in the source, not on this page.

New to bomify? Start with [Getting started](../getting-started/index.md)
instead — this section assumes you already know what you're looking for.

Every command also accepts `bomify --help` / `bomify <command> --help`
directly from the terminal, which is the same content shown here.
