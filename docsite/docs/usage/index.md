# Usage

The CLI reference, generated from bomify's own `--help` output, so it
always matches the binary. To fix something here, change the command's
`Short`/`Long` or flag descriptions in the source. `bomify <command>
--help` shows the same content.

New to bomify? Start with [Getting started](../getting-started/index.md).
